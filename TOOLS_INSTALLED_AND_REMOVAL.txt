VIVADO BUILD CACHE
------------------

The complete PYNQ build uses D:\NeuraEdgeBuild by default because Vivado warns
that the workspace's downloaded path can exceed the Windows 260-character limit
inside generated block-design IP trees. This is generated build data, not an
installed program, service, PATH entry, registry setting, or startup task.
Set NEURAEDGE_VIVADO_BUILD_ROOT before running the build to choose another
location. Removal: delete D:\NeuraEdgeBuild only when no Vivado build is active.
